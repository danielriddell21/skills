# sticky-notes

Mod. `/sticky` opens a shared checklist pane. Claude edits it through the `mcp__sticky-notes__tasks` tool (`add`, `done`, `list`); you tick items with the **Done** button. The list lasts for the session.

You can add a note yourself from the pane (the **add a note** box), tick it with **Done**, and sweep finished ones with **Clear done**.
