# stop-you-violated-the-law

Mod. After a *light* turn on opus (few tool calls, short reply) it toasts "STOP! You violated the law!" and suggests sonnet or haiku. It only nags; it never switches models or blocks anything.

Options: `maxTools` (2), `maxOutputTokens` (400), `cooldownTurns` (5). The thresholds are heuristics.
